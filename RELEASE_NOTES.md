Laramac is a free local web development environment for macOS.

## New in 0.12
- **Downloads have a new home.** Updates, the one-line installer and PHP builds now come from [Pino10/laramac-releases](https://github.com/Pino10/laramac-releases). Your copy of Laramac moves over by itself with this update; nothing else changes.
- **A fuller guide.** The README now walks through installation and every feature, with screenshots.

## Download
- **Apple Silicon:** Laramac-0.12.0-arm64.dmg
- **Intel:** Laramac-0.12.0-x64.dmg

Or install and update from Terminal without the "Open Anyway" step:
`curl -fsSL https://raw.githubusercontent.com/Pino10/laramac-releases/main/install.sh | bash`
